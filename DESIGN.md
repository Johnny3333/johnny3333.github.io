# Portfolio design

Preserve the established Luka academic identity: Libre Baskerville headings, Source Sans 3 body text, a restrained warm neutral background, rust accents, and forest green for the featured scAnyOmics project. Fonts are bundled locally with their licenses.

The desktop homepage has a profile column and a flexible content column. At narrow phone widths the profile becomes a compact row above the introduction. Research interests use small semantic line icons, descriptive headings, and horizontal rules. Source figures provide the visual evidence.

Research opens with the original overview artwork from the supplied presentation, with responsive HTML labels for SMART, ProCLIP, and scAnyOmics. Project sections explain the biological question and contribution. Manuscript readers share one implementation and use local page previews so they do not depend on browser PDF plugins.

Keyboard focus is visible. Phone navigation has an expanded state. Figures open in native modal dialogs with Escape and focus return. Reduced motion disables transitions and animation. Light and dark themes use the same semantic color tokens.

Selected Work uses raised project surfaces with layered shadows, a fine inset rim, and restrained elevation on hover or keyboard focus. All three project covers use matching panels from the supplied research overview. The virtual-cell panel floats above the scAnyOmics forest-to-jade surface. ProCLIP and SMART use the corresponding panels from the supplied research overview as visual covers, with copper and sage accents. Pointer highlights are decorative and disabled for reduced motion.

Education uses two credential folios with institution marks, dates, degree details, and a compact status/GPA row. Research internships share a date rail and separate content rows. Actual links use soft gradient surfaces or animated marker underlines, with keyboard focus and reduced-motion alternatives. The scAnyOmics publication lists arXiv without an identifier or a Paper link until these are supplied.

ProCLIP now follows scAnyOmics in Publications, linking to the existing local manuscript page. Its workflow appears before the search reader in a paper-like figure stage with a concise reading guide. Patent uses the same publication typography with a restrained document mark and the supplied external reference. The manuscripts-in-preparation list is removed.

Publications v5 uses a single editorial list: shared text baselines, consistent row rhythm, equal-sized uncropped figure frames, and quiet arXiv/manuscript status labels. All six thumbnail figures have native zoom buttons. Phone layouts keep the title full width and place a compact figure beside the metadata. Paper metadata, order and destinations are unchanged.

Patent v6 reuses the publication bibliography layout and responsive row, including matching rules, typography, spacing, link feedback and figure-frame dimensions. The decorative document mark is not interactive; citation data and the supplied destination are preserved.
