# Zhaoqi Song · Academic homepage

A responsive, buildless academic portfolio based on Luka Homepage Template.

Open `index.html`, or serve this directory with `python3 -m http.server 8000`. Upload the complete directory contents to the existing GitHub Pages repository to deploy. This local revision has not been published.

Pages: `index.html`, `research.html`, `scanyomics.html`, `proclip.html`, and `cv.html`.

Both manuscript readers support page-level full-text search, page previews, navigation, image enlargement, and original PDF downloads. Fonts, interface icons, and document previews are local assets.

See [中文使用说明](README.zh-CN.md) for file locations and maintenance instructions. Template attribution and original license are retained.
