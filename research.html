scAnyOmics: Any-to-Any completion of multi-omics virtual cells

The University of Tokyo · The Hong Kong Polytechnic University · Xiamen University

Any observed modality can inform any missing modality. scAnyOmics uses scRNA-seq, ADT, or ATAC, alone or in combination, to reconstruct unmeasured molecular profiles in a shared virtual cell representation.

Available inputRNA / ADT / ATACAny single modality or combination
Missing targetRNA / ADT / ATACCross-modal reconstruction

Core capability

Any-to-Any modality completion. Learn from incomplete profiles and predict a target molecular modality from the available measurements.

Downstream applications

Cell Type Annotation, Perturbation Response prediction, and Ageing Clock modeling using the learned cellular representation.

My contribution

Developing modality-specific adapters, masked multimodal fusion, and foundation-model distillation for incomplete single-cell multi-omics data.

Current status

Ongoing research. The current manuscript evaluates cross-modal reconstruction and explores downstream applications.
